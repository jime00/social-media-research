The technical and statistical roadmap scheduled for executing empirical evaluations in upcoming assignments:

🛠️ Technical Tools

Exploratory data analysis and data processing will be implemented using Python data science libraries:

  • Pandas & NumPy: Data cleaning, transformation, and tabular structuring.
  • Matplotlib & Seaborn: Distribution plots and correlation heatmaps.
  • Scipy / Statsmodels: Statistical significance testing.

📈 Evaluation Procedures

Step-by-step statistical methods planned for the dataset:

  • Univariate Statistics: Screen time histograms and normality checks.
  • Bivariate Correlations: Testing screen time against sleep and GPA.
  • Hypothesis Testing: Evaluating statistical support for H1 and H2.
