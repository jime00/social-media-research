🧹 Eight Core Data Cleaning & Validation Areas

The 500,000-record dataset was systematically audited and processed across eight primary data quality dimensions:

1

Missing Values

An exhaustive audit across all 48 columns confirmed that 47 columns have 0 missing values. Exactly one variable (brain_rot_level) contained 6,262 null entries (1.25%). Verification confirmed these correspond strictly to records where brain_rot_index == 0.0; these were cleanly imputed as 'None' to preserve complete data integrity without distortion.

2

Duplicate Records

Checked 500,000 rows across primary keys (student_id) and full-row tuples. Exactly 0 duplicate records were found, verifying that every survey entry represents an independent, unique participant.

3

Incorrect Data Types

All 48 attributes were parsed and validated for type fidelity. Numeric indicators (including screen time, weekly study duration, attendance rates, and productivity scores) are strictly formatted as 64-bit floating point numbers (float) or integers (int), eliminating formatting string conflicts.

4

Inconsistent Formats

String columns (such as country, development_level, device_access, and gender) were audited for inconsistent whitespace, improper casing, and non-ASCII character artifacts, ensuring standardized text normalization across all 50 surveyed nations.

5

Invalid Values

Domain logic checks verified that all numeric measures fall within biologically and mathematically plausible bounds: daily screen time (0.0 to 9.0 hrs), sleep duration (4.0 to 9.0 hrs), class attendance rate (63.0% to 100.0%), and respondent age (15 to 25 years). No impossible values or negative activity hours were present.

6

Outliers

Screen time distribution was evaluated using the Interquartile Range method (Q1 = 2.46 hrs, Q3 = 4.19 hrs, IQR = 1.73 hrs). The upper fence was calculated as 6.79 hours/day. While 14,103 students (2.82%) report screen times between 6.0 and 9.0 hours, these were confirmed as legitimate high-intensity digital usage rather than sensor errors, and were retained for empirical modeling.

7

Inconsistent Categorical Values

Categorical variables across all 50 countries, 3 economic development tiers (Developing: 210,346; Developed: 149,548; Underdeveloped: 140,106), 4 device types, and 3 family income tiers were cross-tabulated, confirming zero spelling variants or inconsistent classifications.

8

Data Transformations

Daily screen time was converted into standardized behavioral tiers: Low (≤ 3.0 hrs, 40.9%), Moderate (3.0–5.0 hrs, 48.2%), and High (> 5.0 hrs, 10.8%). Additionally, a binary risk indicator (at_risk = 1 if academic_risk_score > 0) was engineered for machine learning classification.

🔍 Deep-Dive Investigation: Zero-Inflation in Academic Risk Score

During exploratory data quality auditing, a prominent distributional anomaly was detected in academic_risk_score: exactly 483,134 records (96.63%) have a value of 0.0, while only 16,866 records (3.37%) possess positive risk values (ranging from 0.001 to 24.07, mean = 3.27).

Investigation & Resolution: Bivariate conditioning reveals that academic_risk_score operates as a hurdle / threshold penalty function. Healthy students with standard attendance (≥ 90%), adequate sleep (≥ 6 hrs), and moderate screen time have zero academic risk. A positive score triggers exclusively when digital addiction and screen time exceed critical resilience thresholds, eroding protective academic buffers. Therefore, rather than treating the zeros as missing data or imputing them, we model academic outcomes using two complementary strategies: continuous regression on academic productivity (productivity_score) and weekly study hours, paired with binary classification for identifying high-risk students (academic_risk_score > 0).

🔬 Research Connection

Systematic data cleaning and validation across all 500,000 records establishes rigorous empirical reliability. By verifying variable types, resolving zero-inflation mechanics, and categorizing usage tiers, we ensure that subsequent exploratory data analysis (EDA), relational SQL queries, and predictive machine learning models reflect genuine behavioral relationships rather than data artifacts.
